# 重点关注事项说明

## 高风险事项说明

本次审核发现3项高风险不合规事项，均涉及违反监管硬性指标，存在监管处罚风险：

1. **安联安行万里境外旅行互联网意外伤害保险赔付率连续三年低于50%且保费超500万**：该产品过去三年再保后综合赔付率分别为29%、41%、47%，三年平均值仅39%，远低于50%的监管红线，且2025年保费达2,492.10万元，连续三年超过500万元，完全符合《意外伤害保险业务监管办法》第十条规定的强制费率调整条件，但未见公司采取费率调整措施。这是最严重的违规事项，可能导致监管责令整改及处罚。@@WEKNORA_HTML_PLACEHOLDER_18@@

2. **北大方正人寿团体意外伤害保险B款费用率严重超标**：该产品变动费用率达118%，是监管上限（25%）的4.7倍，严重违反意外险附加费用率监管规定。虽公司称系历史账务清理导致，但费用率数据本身已严重超标，需深入核查实际原因并纠正。@@WEKNORA_HTML_PLACEHOLDER_19@@

3. **互联网人身保险产品偏差≥50%未履行主动报告及披露义务**：安联安康e生互联网医疗保险产品组合全年四个季度赔付率偏差均超过50%（61.98%-79.94%），另有2款新上市产品偏差达100%。按照定价回溯机制要求，偏差≥50%的产品须在次年1月15日前主动报告、1月20日前公开披露，但报告中未见相关程序履行的说明。@@WEKNORA_HTML_PLACEHOLDER_20@@@@WEKNORA_HTML_PLACEHOLDER_21@@

## 需进一步核实事项

1. **安联境外旅行(畅游版)互联网意外伤害保险**：该产品2023年10月上市，2025年保费4,908.23万元，三年综合赔付率分别为0%、8%、26%，虽因上市不满三年暂不触发第十条强制调费率条件，但需关注2026年是否将触发调费条件，公司应提前做好准备。

2. **北大方正人寿60款低保费在售产品**：需进一步核实每款产品的年度累计销售件数和产品使用年限，以确定其中有多少款同时满足"保费<100万+件数<5000件+使用满一年"的低销量产品强制退出条件。

3. **航空意外险特别准备金计提**：需核实安联顺畅游V等航空意外险产品是否按自留毛保费的5%计提特别准备金，报告中未明确提及。

4. **个人养老金业务信息披露**：因法律法规库未收录《关于保险公司开展个人养老金业务有关事项的通知》（银保监规〔2022〕17号）全文，需对照原文进一步核查个人养老金业务经营报告的披露内容完整性。

5. **互联网人身保险产品命名规范**：安联人寿在售8款互联网人身保险产品名称均包含"互联网"字样，符合命名规范要求，但需进一步核查是否存在非互联网产品使用"互联网"字样或互联网产品名称不含"互联网"字样的情况。

# 合规性总体评价

本次审核覆盖了待审文档库中的全部21份文档，涉及安联人寿和北大方正人寿两家保险公司的产品经营报告、意外险业务经营报告、互联网人身保险业务报告、定价回溯报告、个人养老金业务报告等多个类别。审核依据法律法规库中8部核心法规文件，从产品定价与费率管理、定价回溯管理、互联网人身保险业务、产品管理与退出、团体保险业务、信息披露与报送、个人养老金业务等多个维度进行了系统审查。

总体来看，两家公司的产品经营管理基本框架健全，均按监管要求报送了各类年度报告，主要业务指标（如偿付能力、风险综合评级、责任准备金覆盖率等）符合互联网人身保险业务准入条件。但在产品定价管理和回溯执行层面存在较为突出的问题，特别是意外险赔付率长期偏低未及时调整费率、团体意外险费用率严重超标、互联网人身保险定价回溯偏差分级管理措施落实不到位等问题，违反了监管的硬性指标要求，存在较高的监管处罚风险。

建议两家公司：（1）立即对触发强制调费率条件的意外险产品启动费率下调工作；（2）全面梳理费用率超标产品，制定切实的费用管控措施；（3）严格落实互联网人身保险定价回溯偏差分级管理，按规定履行主动报告和信息披露义务；（4）对低销量产品进行全面排查，符合退出条件的应主动停售；（5）建立健全产品全生命周期合规管理机制，加强日常监测和自查，确保各项经营指标持续符合监管要求。

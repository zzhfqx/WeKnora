## 第一章 内置 MCP Server（官方推荐）

### 1.1 概述

内置 MCP Server 是 v0.8.2 起引入的官方推荐方案，直接集成在 WeKnora 主服务中。管理员在 Web UI「设置 → 发布与集成 → MCP Server」中创建端点，每个端点独立配置令牌、知识库范围、工具分组和限流，对外通过 Streamable HTTP 暴露。

**核心特点：**
- **零部署成本**：随主服务一起运行，无需额外进程
- **端点级隔离**：每个端点有独立令牌、知识库范围、工具白名单、限流
- **Streamable HTTP**：标准 HTTP 协议，跨网络调用方便
- **工具分组**：retrieve（检索）/ chat（问答）/ wiki / ingest（写入）四大分组
- **安全默认**：只读工具默认启用，写入工具（ingest）默认关闭
- **权限复用**：与 REST API 共用同一套 API Key Scope 权限模型

**接入地址**：`https://你的域名/mcp/<endpoint_id>`

**客户端配置示例：**
```json
{
  "mcpServers": {
    "weknora": {
      "transport": "streamable-http",
      "url": "https://kb.example.com/mcp/end_xxx",
      "headers": {
        "Authorization": "Bearer mcp_xxxx"
      }
    }
  }
}
```

**代码位置：**
- 服务实现：`internal/mcpserver/`
- 类型定义：`internal/types/mcp_endpoint.go`、`internal/types/mcp_endpoint_tools.go`
- HTTP 路由：`internal/router/routes_mcp_endpoint.go`
- 鉴权中间件：`internal/middleware/mcp_endpoint_auth.go`

#### 1.3.5 `read_document` — 阅读文档

| 项目 | 说明 |
|------|------|

**输入参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |

## 第二章 CLI MCP Server (`weknora mcp serve`)

### 2.1 概述

CLI MCP Server 是 WeKnora 命令行工具内置的 MCP 服务，通过 `weknora mcp serve` 启动。它提供一个**精选的 10 工具集**，以只读操作为主，专为 IDE 侧的 AI Agent 设计。

**核心特点：**
- 基于 Go 实现，使用 `modelcontextprotocol/go-sdk`
- 仅支持 **stdio** 传输方式（通过标准输入输出通信）
- 认证继承自当前 CLI profile（`--profile` 或 `WEKNORA_PROFILE`）
- 启动时立即校验认证，未配置则直接退出（`auth.unauthenticated`）
- 日志输出到 stderr，stdout 保留给协议流量
- 刻意排除了破坏性操作（创建/删除/上传），Agent 修改数据需走 CLI 的 exit-10 确认机制
- **跨版本稳定**：v0.8.0 / v0.8.2 / v0.8.3 均为 10 个工具，工具集完全一致

**启动命令：**
```bash
weknora mcp serve
```

**MCP 客户端配置示例：**
```json
{
  "mcpServers": {
    "weknora": {
      "command": "weknora",
      "args": ["mcp", "serve"]
    }
  }
}
```

**代码位置：**
- 命令定义：`cli/cmd/mcp/mcp.go`、`cli/cmd/mcp/serve.go`
- 工具实现：`cli/internal/mcp/tools.go`
- 服务入口：`cli/internal/mcp/server.go`

## 第三章 Python MCP Server (`mcp-server/`)

### 3.1 概述（⚠️ 已弃用）

Python MCP Server 是早期独立部署的 MCP 服务，功能完整，支持知识库、文档、模型、会话、聊天、智能体、分块、Wiki 等全生命周期管理。

**⚠️ 弃用说明：**
- 自 **v0.8.2** 起官方标记为弃用（Deprecated）
- 推荐使用**服务端内置 MCP Server**（在 Web UI「设置 → 发布与集成 → MCP Server」中创建端点）
- 本目录仅为兼容旧部署保留，**后续版本将移除**
- v0.8.3 源码中仍然存在，但不再是推荐方案

**核心特点：**
- 基于 Python 实现，使用 `mcp` SDK（MCPServer / FastMCP）
- 共 **31 个工具**（v0.8.2 和 v0.8.3 相同；v0.8.0 有 30 个，缺少 `update_knowledge_from_text`）
- 支持 **三种传输方式**：stdio、SSE、HTTP（Streamable HTTP）
- 使用 **API Key** 认证（`X-API-Key` 请求头）
- 支持文件上传、文档创建/更新/删除等写操作
- 可作为 Python 包安装（PyPI 包名：`tencent-weknora-mcp`）
- 提供 Docker 镜像部署

**代码位置：** `mcp-server/weknora_mcp_server.py`

### 4.4 选择建议

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| **给第三方封装 MCP**（dsh、opencode 等） | 内置 MCP Server | 端点隔离、独立令牌、知识库范围可控、Streamable HTTP 跨网络 |

| **需要完整管理能力**（创建知识库/模型/租户） | Python MCP Server | 31 个工具最全，但注意已弃用 |
| **生产环境部署** | 内置 MCP Server | 官方推荐、随主服务升级、有 Web UI 管理 |
| **二次开发学习** | 内置 + CLI 都看 | 内置看架构设计，CLI 看 Go 实现模式 |
| **兼容老项目** | Python MCP Server | 仅用于兼容，建议尽快迁移到内置 MCP |
